## Cove Windows Toolkit v3.4.0

Security and reliability release. 65 confirmed root causes from a repository-wide
audit were addressed across privilege handling, rollback integrity, frontend IPC,
parsing correctness, and release engineering.

### Downloads

| File | Type |
|------|------|
| `Cove-Windows-Toolkit-3.4.0-Setup.exe` | Windows Installer |
| `Cove-Windows-Toolkit-3.4.0-Portable.exe` | Standalone (no install; per-user AppData state) |

Each asset ships with a matching `.sha256` sidecar. Verify with:

```powershell
Get-FileHash .\Cove-Windows-Toolkit-3.4.0-Setup.exe -Algorithm SHA256
```

### Bugs fixed

**Cleanup**
- Cleanup no longer fails partway through a sweep. It uses native handle-relative
  traversal that does not follow reparse points, skips locked children instead of
  aborting, deletes nested folders post-order, and is idempotent for folders that
  are already gone.
- Added sanitized support logs so a failed run can be diagnosed without exposing
  user paths or machine identifiers.

**Privileged and destructive operations**
- Elevated uninstall is limited to revalidated HKLM MSI product codes executed
  through a trusted System32 `msiexec`. Automatic deletion of leftovers is removed.
- Elevated startup-folder moves are disabled. Run-key toggles are limited to
  approved roots, refuse collisions, and roll back partial copies on failure.
- Adjacent portable state is disabled; state now lives in per-user AppData.
- Temperature collection no longer installs the PawnIO driver; the legacy
  driver-installing implementation was deleted.
- System tools resolve through System32 / Known Folder APIs instead of bare
  executable names or inherited environment variables.

**Rollback, history, and data integrity**
- The first pre-change snapshot is preserved until undo.
- Registry state is re-read and checked immediately before mutation.
- Corrupt rollback or history data fails closed instead of deleting values or
  silently rendering an empty history.
- Apply/undo/preset mutations are serialized; only the latest snapshot-backed
  history row is undoable.

**Frontend**
- Validated command envelopes, worker-failure fallbacks, in-flight guards,
  stale-generation rejection, and surfaced external action failures that
  previously failed silently.

**CI**
- Fixed the pnpm cache path that broke frontend dependency caching.

### Optimizations

- **Faster startup / smaller bundle.** Feature panels load per route through a
  panel registry of dynamic imports wrapped in Suspense, cutting the initial
  chunk from 379 kB to 274 kB. A build-output test fails the build if panels
  become eager again.
- **Health checks no longer spawn PowerShell.** System-drive free space is read
  via `GetDiskFreeSpaceExW` and physical memory via `GlobalMemoryStatusEx`
  instead of PowerShell/CIM queries, removing per-probe process spawns. Both
  findings are guarded against nonsensical totals, with unit coverage for the
  severity thresholds and unknown-metric fallbacks.

### Release engineering

- Pinned Rust/Node/pnpm toolchains and all GitHub Action SHAs.
- Scoped release write permission to the publish job only.
- Added MIT license and package metadata.
- Added a `cargo audit` warning gate so new maintenance advisories block CI.
